# 🔨 میلانو بیلدر — راهنمای فارسی

**فقط یک جمله کوتاه بنویس → نرم‌افزار آماده نصب تحویل بگیر.**
این پروژه دقیقاً مدل برنامه داخل اسکرین‌شات (YBee) را پیاده می‌کند:

- 📱 **اپ اندروید** (`android/`) با همان ظاهر: تیتر *«امروز می‌خوای چی بسازی؟»*،
  دکمه‌های پیشنهادی، کادر ایده، لاگ زنده ساخت، پیش‌نمایش، **دانلود و نصب مستقیم APK** و اشتراک با QR.
- 🖥️ **سرور بیلد** (`server/`) که از روی ایده، پروژه واقعی چندسکویی می‌سازد:
  - 🪟 خروجی ویندوز: فایل **`.exe`** + فایل نصب **`Setup.exe`**
  - 🤖 خروجی اندروید: فایل **`.apk`** با نصب مستقیم روی گوشی
  - 📦 سورس‌کد کامل + 👁 پیش‌نمایش زنده (همیشه رایگان و فوری)
  - 🌐 رابط وب داخلی (بدون نیاز به اپ، داخل مرورگر)

## شروع سریع (۲ دقیقه)

```bash
cd server
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

مرورگر را باز کن: http://localhost:8000
بنویس: «یک برنامه وبلاگ‌خوان بساز» → ساخت را زنده تماشا کن → سورس + پیش‌نمایش را بگیر.

## گرفتن خروجی واقعی exe / Setup / apk

سه راه وجود دارد (به ترتیب پیشنهاد):

### ۱. بیلد ابری با گیت‌هاب اکشن (پیشنهاد ⭐ — بدون نصب هیچ‌چیز)

```bash
export GITHUB_REPO="Companymeelano/Server"
export GITHUB_TOKEN="ghp_..."   # دسترسی repo و actions:write
```

بعد از این، هر ایده‌ای که در اپ/وب ثبت شود، سرور به‌صورت خودکار ورک‌فلو
`build-generated.yml` را اجرا می‌کند، منتظر می‌ماند و فایل‌های `.exe` و
`Setup.exe` و `.apk` را به همان صفحه بیلد اضافه می‌کند؛ داخل اپ، دکمه **📲 نصب**
فایل APK را مستقیم نصب می‌کند.

راه دستی: تب **Actions** ریپو → ورک‌فلو **build-generated** →
**Run workflow** → قالب و اسم برنامه را بده → فایل‌ها در Artifacts.

### ۲. سرور با ابزار بیلد

- ویندوز: `pip install pyinstaller` (و NSIS برای Setup) → خروجی exe روی همان سرور.
- اندروید: JDK 17 + Android SDK + Gradle → خروجی APK روی همان سرور.

### ۳. حالت ساده (بدون ابزار)

باندل سورس شامل اسکریپت یک‌کلیکه است:

- ویندوز: `windows/build_exe.bat` → `dist/*.exe`، بعد `makensis installer/installer.nsi` → `Setup.exe`
- اندروید: پوشه `android/` یک پروژه Gradle آماده است: `gradle :app:assembleDebug`

## هوش مصنوعی (اختیاری)

بدون کلید، **موتور قالب داخلی** (۷ قالب: وبلاگ، ماشین‌حساب، یادداشت، تاس، هواشناسی،
فروشگاه، پایه — فارسی و انگلیسی) بلافاصله جواب می‌دهد. با کلید سازگار با OpenAI،
طراحی برنامه برای هر ایده‌ای اختصاصی می‌شود:

```bash
export OPENAI_API_KEY="sk-..."
export OPENAI_BASE_URL="https://api.openai.com/v1"
```

یا داخل اپ: **تنظیمات ← کلید هوش مصنوعی**.

## ساخت فایل APK خودِ اپ بیلدر

- راحت‌ترین راه: تب **Actions** → ورک‌فلو **android-builder** → فایل APK در Artifacts.
- یا با Android Studio پوشه `android/` را باز کن و Run بگیر.

داخل اپ (تنظیمات) آدرس سرور را وارد کن:

- شبیه‌ساز اندروید: `http://10.0.2.2:8000`
- گوشی واقعی (هم‌شبکه با کامپیوتر): مثل `http://192.168.1.5:8000`

## API (خلاصه)

- `POST /api/v1/jobs` با `{idea, platforms: ["android","windows"], lang}`
- `GET /api/v1/jobs/{id}` وضعیت + لاگ + فایل‌ها (یا SSE در `/logs/stream`)
- `GET /api/v1/jobs/{id}/preview` پیش‌نمایش زنده
- `GET /api/v1/artifacts/{id}/{file}` دانلود فایل
- `GET /api/v1/health` → `{ok, version, ai, cloud_build}`
